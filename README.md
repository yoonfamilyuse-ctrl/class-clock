# Class Clock

레트로 터미널 스타일의 학교·기숙사용 시계입니다. HTML 파일 하나(`index.html`)로 동작하고, 빌드 과정이 없습니다.

- 사이트: https://yoonfamilyuse-ctrl.github.io/class-clock/

## 화면

| 칸 | 내용 |
|---|---|
| 시계 | 한국 표준시(KST, Asia/Seoul) 날짜·요일, 시:분, 초 |
| 교시 PERIOD | 지금 일정 이름, 끝나는 시각, 남은 시간, 진행 막대. 일정 사이는 `BREAK`, 첫 일정 전은 `STANDBY`, 마지막 일정 뒤는 `DISMISSED`, 일정이 없는 요일은 `DAY OFF` |
| 디데이 D-DAY | 가장 가까운 날짜를 크게, 그다음 두 개를 작게 표시. 지난 날짜는 자동으로 빠짐 |
| 외부 EXTERNAL | 현재 기온, 15분마다 갱신 |

배치는 화면에 따라 바뀝니다. 맥북과 패드 가로는 좌우 배치, 휴대폰·패드 세로는 위아래로 쌓입니다. 휴대폰 가로(높이 540px 이하)는 스탠바이 화면입니다. 검은 배경 왼쪽에 큰 시계, 오른쪽에 교시·디데이·외부 위젯이 하나씩 나오고 10초마다 넘어갑니다. 위젯을 위아래로 끌면 카드가 손가락을 따라 움직이고, 놓으면 스프링처럼 다음·이전 카드로 넘어갑니다. 짧게 끌면 제자리로 돌아가고, 탭하면 다음 카드로 넘어갑니다. iPhone·iPad에서는 Safari 공유 → "홈 화면에 추가"로 앱처럼 열 수 있습니다.

## 설정

왼쪽 위 `SYNC` 버튼을 누르면 설정이 열립니다. 설정은 기기별로 브라우저(localStorage)에 저장됩니다.

**시간표**: 한 줄에 하나씩 씁니다.

```
[요일] HH:MM-HH:MM 이름
월화수목금 07:00-07:50 아침식사
월 08:30-09:20 FREE
# 메모 줄
```

요일은 `월`, `월화수목금`, `매일`처럼 앞에 붙입니다. 요일을 생략하면 매일 적용됩니다.

**디데이**: `YYYY-MM-DD 이름` 형식으로 한 줄에 하나씩 씁니다. 예: `2026-12-15 기말고사`

**아날로그 색**: 두 가지 방식 중 고릅니다. `테마 따르기`는 화면 테마의 네 색을 쓰고, `흰색 + 강조색 (애플)`은 아이폰 스탠바이처럼 숫자·바늘·눈금·날짜는 흰색, 초침·가운데 링·알람 아이콘은 강조색, 요일은 두 번째 강조색으로 그립니다(배경은 검정). 강조색은 9가지이고 기본 Classic은 초침 주황, 요일 빨강입니다. ANALOG가 보일 때 시계를 꾹 누르면 색 패널에 "아날로그 색" 줄이 함께 나옵니다.

**아날로그 설정** (`SYNC` → 아날로그): 초침 움직임(부드럽게/1초씩), 다음 알람 시각(비우면 왼쪽 칸 숨김). 주소 끝에 `?debug`를 붙이면 눈금 기준 사각형과 시 방향 선이 겹쳐 보입니다. 치수는 모두 `index.html`의 `CONFIG`에 문자판 높이 H의 배수로 모여 있습니다.

**색 테마**: 시계를 꾹 누르면(0.5초) 아래에서 색 패널이 올라옵니다. 테마 원을 탭하면 바로 바뀌고, `완료`로 확정, `✕`로 원래 색으로 돌아갑니다. 시계를 왼쪽으로 밀면 다음 테마, 오른쪽으로 밀면 이전 테마로 바뀝니다(바뀔 때 이름이 잠깐 뜸). 설정의 "색 테마"에서 골라도 됩니다. 시계(모든 스타일), 위젯, 버튼까지 화면 전체 색이 함께 바뀝니다. ANALOG는 숫자·눈금에 이름표 색, 시침·분침에 시각 색, 초침·가운데 링·알람 아이콘·요일에 포인트 색, 알람 시각·날짜에 정보 색을 씁니다. 고르는 순간 화면에 바로 미리 보이고, 취소하면 원래대로 돌아갑니다. 야간 모드는 어떤 테마에서든 빨간색으로 바뀝니다.

| 테마 | 색 (시각 / 정보 / 포인트 / 이름표) |
|---|---|
| SIGNAL | 빨강 / 초록 / 주황 / 노랑 (기본) |
| TIDE | 하늘 / 민트 / 산호 / 모래 |
| SUNSET | 분홍 / 하늘 / 주황 / 노랑 |
| MEADOW | 라임 / 시안 / 주황 / 노랑 |
| NEON | 마젠타 / 시안 / 노랑 / 보라 |

**시계 스타일**: 시계를 탭하면 다음 스타일, 위로 밀면 다음, 아래로 밀면 이전 스타일로 바뀝니다. 설정에서 고를 수도 있고, 고른 스타일은 저장됩니다.

| 스타일 | 모양 |
|---|---|
| RETRO | 큰 디지털 숫자 (기본) |
| ANALOG | 아이폰 스탠바이(iOS 17) 아날로그를 재현한 직사각형 문자판. 숫자는 12·3·6·9만, 나머지 시는 가장자리에서 뻗는 긴 눈금(모서리 쪽일수록 김), 분 눈금 48개, 흰 캡슐 바늘, 부드럽게 도는 초침, 가운데 양옆에 다음 알람과 요일·날짜. 색은 색 테마를 따름 |
| LED | 7세그먼트 숫자, 꺼진 칸이 희미하게 보이는 LED 느낌 |
| STACK | 둥글고 굵은 숫자로 시와 분을 위아래로 크게, 두 색으로 살짝 겹쳐 표시. 숫자가 바뀔 때 통통 튀며 나타남 |

**시계만 보기**: 가로 화면(휴대폰·패드·컴퓨터)에서 `CLOCK` 버튼을 누르면 위젯 없이 검은 화면에 시계만 크게 나옵니다. 다시 누르면 돌아옵니다. 설정의 "가로 화면 보기"에서도 고를 수 있고, 고른 보기는 저장됩니다. 세로 화면에서는 적용되지 않습니다.

**야간 모드**: 화면의 모든 색을 어두운 빨간색 쪽으로 바꾸고 전체를 어둡게 합니다. 흰색·초록·파란 빛을 내지 않아 밤에 켜 두기 좋습니다.

- 예약: 기본값은 00:00–06:00입니다. 2자율학습이 23:50에 끝나고 06:00에 기상하는 일과에 맞췄습니다. 시작이 끝보다 늦으면 자정을 넘기는 구간으로 처리합니다.
- `NIGHT` 버튼: 언제든 직접 켜고 끕니다. 직접 바꾼 상태는 다음 예약 시각(켜짐 또는 꺼짐)까지 유지됩니다.
- 밝기(10–100%)와 빨간 정도(0–100%): 설정에서 슬라이더를 움직이는 동안 바로 미리 보입니다. 화면 백라이트 밝기 자체는 웹페이지가 바꿀 수 없어 기기 설정을 따릅니다.

**위치**: 기온을 가져올 위도·경도입니다. 기본값은 서울(37.5665, 126.978)입니다.
